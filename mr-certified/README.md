# MERQO Stores

Social-commerce prototype: TikTok-style buyer feed, certified sellers, marketers, business records, Certified AI (mock).

## Run
    npm install
    npm run dev

All data is mock; payments and verification are simulated.

## Structure
- `src/data.js` mock products, orders, ledger, AI answers, helpers
- `src/App.jsx` state + screen routing
- `src/components/` one file per screen/component
- `src/styles.css` all styling
